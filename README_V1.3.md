# CookAI V1.3

ต่อยอดจาก V1.2 Final (ดู `V1.3_IMPACT_REPORT.md`) — Core AI / Usage / Subscription / Payment Sandbox / Admin ไม่เปลี่ยน

## ฟีเจอร์ใหม่
1. **เมนูที่ทำแล้ว** — ตัวเลขหน้าแรกอัปเดตจริงเมื่อกด "ทำเสร็จเรียบร้อย" (กันนับซ้ำด้วย event id) · แตะตัวเลข = ดูประวัติ
2. **ทำเมนูนี้** — เมนูแนะนำหน้าแรก → ดูวัตถุดิบ(ติ๊กความพร้อม)+โภชนาการ → Cook Mode (ไม่เรียก AI)
3. **ตัวอย่างวัตถุดิบ** — กดซ้ำเปลี่ยนชุด 6 ชุด ไม่ซ้ำจนครบรอบ
4. **ดาว + สมุดสูตร** — แตะดาวให้คะแนนได้ · บันทึก/ลบสูตร · เปิดดูในสมุดสูตรของฉัน (แยกต่อ user)
5. **อ่านออกเสียง** (Cook Mode) — เล่น/พัก/อ่านต่อ/หยุด · อ่านต่อเนื่องเมื่อเปลี่ยนขั้นตอน
6. **ระดับฝีมือ** — แตะดูเกณฑ์ (นับจากเมนูที่ทำเสร็จ) · ปรับได้ด้วย `SKILL_LEVELS` ใน `.env`
7. **Auto-slide** ไอเดียประจำวัน
8. **โปรไฟล์ → Personal Nutrition** — แตะวงกลมชื่อ · น้ำหนัก/ส่วนสูง · สวิตช์ ON/OFF (ค่าเริ่มต้น OFF)
9. **เตือน + ปุ่ม "ปรับสารอาหารให้เหมาะกับฉัน"** (เฉพาะเมื่อ ON, ลดสัดส่วนเท่านั้น, ค่าประมาณ ไม่ใช่คำแนะนำทางการแพทย์)
10. **อีโมจิขยับเบา ๆ** (ปิดเองเมื่อผู้ใช้ตั้งลดการเคลื่อนไหว)

## API ใหม่ (ทั้งหมดต้อง login)
`POST /history/complete` · `GET /history` · `GET /stats` · `GET /skill-levels` · `PUT /history/{id}/rating` ·
`POST/GET /recipe-book` · `DELETE /recipe-book/{id}` · `GET/PUT /profile/nutrition` · `POST /nutrition/guidance`
