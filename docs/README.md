# CookAI Architecture Documentation

Copy the `docs` folder into the root of the CookAI V1.3 repository.

Files:
- `docs/Microservices_Architecture.md` — proposed logical architecture and current deployment view.
- `docs/Technology_Stack_Diagram.md` — technology stack diagram.
- `docs/Project_Completion_Assessment.md` — completion self-assessment and release checklist.

The diagrams use Mermaid, which GitHub renders inside Markdown files.
